# Contributing to Tally

Thanks for wanting to help. Tally is not open source: its code is private and every change goes through the author.

## Report a problem or ask for a feature

- Open an [issue](../../issues) with what you did, what you expected and what happened. Add your macOS version and the Tally version (shown in the `.dmg` file name).
- Never paste a token, API key, password or real worklog content into an issue.
- You can also write to alanupermana@gmail.com, or use **Need Help?** in the app.

## Contribute code, fork or build on Tally

Ask first. Write to alanupermana@gmail.com with:

1. who you are and what you want to change or build,
2. why it helps people who log time to Taiga,
3. whether you want to contribute it back or keep a separate version.

If it fits, you get access to the source repository as a contributor, or written permission for a fork. Without that permission, copying, modifying or redistributing Tally is not allowed (see [LICENSE](LICENSE)).
